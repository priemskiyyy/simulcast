# Getting help

Start with the [installation guide](docs/installation.md), [examples](examples/README.md), and [troubleshooting guide](docs/troubleshooting.md). Each adapter has its own README under [packages/adapters](packages/adapters).

For a bug report, include:

- The smallest example that reproduces the issue.
- Simulcast, provider SDK, framework, and runtime versions.
- Expected and actual connection or channel states.
- Whether the issue happens on the first connection, after reconnecting, or during cleanup.

Use [GitHub issues](https://github.com/priemskiyyy/simulcast/issues) for reproducible bugs and feature requests. Remove credentials, access tokens, and private message payloads from examples and logs.

See [CONTRIBUTING.md](CONTRIBUTING.md) to run the test suites or propose a change.
